### איך זה נשאר בעלות אפס
ה-AI מחזיר שורת טקסט לכל סעיף במקום אובייקט JSON:

```
תקרת גבס מונמכת|22|מ"ר|180|finish
```
במקום
```json
{"name":"תקרת גבס מונמכת","qty":22,"unit":"מ\"ר",
 "price":180,"cat":"עבודות גמר ועיצוב פנים"}
```

**64% פחות טקסט.** 60 סעיפים בפורמט הדחוס ≈ 780 טוקנים — פחות ממה
ש-25 סעיפים תפסו קודם. הקוד עובד מול Gemini בשכבה החינמית, כך
שההרחבה לא מוסיפה עלות.

### אין יותר חיתוך בשקט
קודם `.slice(0,30)` מחק סעיפים בלי סימן. עכשיו:
- **יותר מהתקרה** → "זוהו 70 סעיפים, מוצגים 60 — פצל לשני חלקים"
- **תשובה שנקטעה** → "תשובת ה-AI נחתכה באמצע — צלם/פצל לשני חלקים"
